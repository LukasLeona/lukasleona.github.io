# Midnight Rose Wedding Invitation Demo

A premium responsive wedding invitation website with ivory, black, champagne, and dusty-rose styling.

## Open the website

1. Extract the ZIP file.
2. Open `index.html` in a browser.

## Interactive features

- Live countdown timer
- Mobile navigation
- Smooth section reveals
- Downloadable calendar event
- Gallery lightbox
- Demo RSVP confirmation modal
- Interactive guest gift registry
- Guest-added gifts are displayed instantly and saved with `localStorage`
- Guest-added demo gifts can be removed individually or cleared

## Important demo note

The RSVP form does not send information to a server. The gift registry stores additions only in the current browser. Connect these forms to a database, Formspree, Supabase, Firebase, or another backend before production use.

## Editing the date

Open `script.js` and change `CONFIG.weddingDate`.
