# Pamana - Filipino Wedding Website Demo

Open `index.html` in a browser.

## Included
- English copy with Filipino cultural styling
- Barong Tagalog and Filipiniana visual direction
- Poppins body font with Cormorant Garamond display headings
- Responsive desktop, tablet, and mobile layouts
- Countdown, mobile menu, active navigation, scroll reveals, parallax, image lightbox, RSVP popup, calendar download, and guest gift registry
- Registry entries are saved in the current browser using localStorage

## Easy content updates
Edit the names, date, venue, and contact details in `index.html`. Change the countdown date in the `data-date` attribute of `.countdown`. Update calendar details in `script.js`.

This is a frontend demo. RSVP submissions are not sent to a server.
