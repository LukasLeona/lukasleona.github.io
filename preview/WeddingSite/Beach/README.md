# Georgia Beach Wedding Website

A responsive, single-page wedding invitation demo for a beach wedding on Jekyll Island, Georgia.

## Open the website

Open `index.html` in a browser. No installation or build command is required.

## Update the couple and date

Edit `WEDDING_CONFIG` at the top of `script.js`.

## Demo interactions

- The RSVP form validates and displays a confirmation popup.
- Available registry gifts can be reserved and change to `Reserved` in the current browser session.
- The premium nine-photo editorial gallery opens each image in a lightbox.
- The calendar button downloads an `.ics` calendar file.
- RSVP and registry information is not transmitted or stored.
