Method & sources

Useful because it’s honest.

Every number keeps its definition, publication date, and source. Generic posting times are clearly labeled as a research baseline.

01

Platform scale

Uses the newest defensible public disclosure found for each network. The metric label stays attached.

02

Age targeting

Uses Pew Research Center’s 2025 U.S. adult adoption survey. Treat it as a benchmark, not a global demographic census.

03

Posting windows

Starts with large-sample 2025–2026 studies, then applies a clearly labeled age-routine adjustment in audience local time.

04

Live signals

Refreshes current Google search trends and recent Wikipedia page views through public, keyless internet endpoints.
