# JVT Philippines Website Concept

A responsive, research-led website concept for JVT Philippines. The site turns the brand's current social-first presence into an owned product-discovery and inquiry experience.

## Highlights

- Immersive full-width hero using an official JVT Philippines brand visual
- Interactive JVT Pulley Set S2 fitment finder
- Product-system overview for CVT, engine, exhaust, suspension, and brake components
- Research-backed brand timeline
- Buyer setup checklist and accessible FAQ
- Tap-to-call, email, map, Facebook, and Shopee conversion paths
- Branded local-response chatbot with an isolated response function for future API connection
- Semantic HTML, structured data, Open Graph metadata, sitemap, and robots metadata
- Keyboard-friendly navigation, visible focus states, reduced-motion support, and mobile-first layouts

## Local preview

Run:

```text
node serve.mjs
```

Then open `http://127.0.0.1:4173/`.

## Content guardrails

The site does not claim live inventory, prices, warranty terms, guaranteed performance gains, dealer counts, or legal compliance. Fitment and availability are confirmation-first. Current company details come from the verified JVT Philippines Facebook page, while brand history is supported by published trade coverage. See `RESEARCH.md`, `ASSET-CREDITS.md`, and `sources.html`.

## Concept status

This is an independent portfolio website concept. It is not an official JVT Philippines website.
